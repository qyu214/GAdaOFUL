# GAdaOFUL Reproducibility Project

## Overview

This repository contains a reproducible simulation pipeline comparing GAdaOFUL with CW-OFUL, Greedy, OFUL, and AdaOFUL under corruption and heavy-tailed rewards.

The designated output is the cumulative-regret comparison figure:

`results/figures/cor+nonlin1.pdf`

## Repository Structure

```text
GAdaOFUL/
├── notebooks/
│   └── original_analysis.ipynb
├── src/
│   ├── config.py
│   ├── utils.py
│   ├── algorithms.py
│   ├── run_experiments.py
│   └── plot_results.py
├── artifacts/
│   └── trajectories/
├── results/
│   └── figures/
├── tests/
├── requirements.txt
├── Makefile
└── README.md
```

- `notebooks/` contains the original analysis notebook for reference. It is not required by the automated reproduction pipeline.
- `src/` contains the refactored simulation and plotting code.
- `artifacts/trajectories/` contains intermediate cumulative-regret trajectories generated by the simulations.
- `results/figures/` contains the final figure.
- `tests/` contains reproducibility and pipeline tests.

## Data

No external dataset is required. All data used for the designated result are generated by the simulation code.

The trajectory files in `artifacts/trajectories/` are generated intermediate outputs and can be regenerated by running the reproduction workflow.

## Environment Setup

The project has been tested with Python 3.13.15.

From the repository root, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the required dependencies:

```bash
python -m pip install -r requirements.txt
```

## Reproduce the Results

Run:

```bash
make reproduce
```

This command runs all simulation repetitions using fixed random seeds, saves the generated trajectories to `artifacts/trajectories/`, aggregates the repeated runs, and generates:

```text
results/figures/cor+nonlin1.pdf
```

No interactive input or manual modification of the code is required.

To run only the simulations:

```bash
make simulate
```

To regenerate the figure from existing trajectories:

```bash
make plot
```

## Run Tests

Run:

```bash
make test
```

The tests check deterministic behavior under a fixed random seed and verify that a small end-to-end pipeline can generate both trajectory files and a figure.
